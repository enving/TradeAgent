
## Purpose

**When to use /handoff**:
- ✅ Mid-session handoff (switching agents)
- ✅ Quick context transfer
- ✅ Need handoff prompt but not ready to commit
- ✅ Passing work to specialist agent (e.g., plan → build)

**When to use /checkpoint instead**:
- ✅ End of work session (full cleanup)
- ✅ Need git commit
- ✅ Need repository cleanup
- ✅ Final handoff for the day

---

## Handoff Workflow

### 1. Read Current State

```bash
# Check current tasks
cat .opencode/tasks.json | jq '.meta, .tasks[] | select(.status == "in_progress")'

# Check git status
git status

# Check recent commits
git log --oneline -5
```

### 2. Identify What to Hand Off

**Questions to answer**:
- What did I accomplish?
- What's in progress?
- What's blocked?
- What should next agent prioritize?
- Any important context/gotchas?

### 3. Generate Handoff Prompt

**🚀 DEPLOYMENT HINWEIS:**
Der Raspberry Pi aktualisiert sich alle 5 Minuten automatisch per Cron-Job (`scripts/pi_auto_update.sh`). 
- **Workflow:** Änderungen lokal fixen -> Tests (falls möglich) -> `git push origin main`.
- **WICHTIG:** Niemals direkt auf dem Pi arbeiten, außer für Debugging per SSH. Der Pi überschreibt lokale Änderungen beim nächsten Pull.

### 4. Output the Handoff Prompt

Display the handoff prompt in a copy-pasteable format:

```
═══════════════════════════════════════════════════════
COPY-PASTE HANDOFF PROMPT BELOW
═══════════════════════════════════════════════════════

[Full handoff prompt from step 3]

═══════════════════════════════════════════════════════
END HANDOFF PROMPT
═══════════════════════════════════════════════════════

✅ Handoff prompt ready!

**What to do now**:
1. Copy the text above
2. Start new agent session (or same session)
3. Paste the handoff prompt
4. Continue work

**If this is end of session**: Use `/checkpoint` instead for full cleanup + git commit
```

## Differences: /handoff vs /checkpoint

| Feature | /handoff | /checkpoint |
|---------|----------|-------------|
| Generate handoff prompt | ✅ | ✅ |
| Update tasks.json | ❌ Manual | ✅ Auto |
| Update docs (agents.md, etc) | ❌ Manual | ✅ Auto |
| Git commit | ❌ No | ✅ Yes |
| Repository cleanup | ❌ No | ✅ Yes |
| Use case | Quick handoff | Session end |
| Duration | 30 seconds | 2-3 minutes |

**Rule of Thumb**:
- **Mid-session**: `/handoff`
- **End-of-session**: `/checkpoint`

## Summary

/handoff command:
1. ✓ Reads current state (tasks.json, git status)
2. ✓ Identifies completed/in-progress/blocked work
3. ✓ Generates structured handoff prompt
4. ✓ Outputs copy-pasteable text
5. ✓ No side effects (no commits, no file changes)

**Purpose**: Fast context transfer between agents
**Duration**: ~30 seconds
**Next Command**: Continue working OR `/checkpoint` when done
